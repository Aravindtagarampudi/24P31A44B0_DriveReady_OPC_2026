
# Day 1 – One Person Company Workshop

## Project
Sweet Crumbs Home Bakery AI Assistant

## Objective
To understand how Large Language Models work, create a basic AI assistant using Groq, and experiment with prompts, temperature, hallucinations, memory and tokens.

## Technologies Used
- Python
- Google Colab
- LangChain
- Groq API
- Prompt Guard

## Tasks Completed
1. Connected to the Groq API.
2. Created a system prompt for Sweet Crumbs Home Bakery.
3. Built a basic AI assistant.
4. Tested customer questions.
5. Explored Prompt Guard.

## Your 10% Experiments
1. Temperature: Compared responses at 0.2 and 1.2.
2. Hallucination: Tested the assistant without its FACTS section.
3. No Memory: Compared separate calls with conversation history.
4. Token Comparison: Compared English and Telugu prompt tokens.
5. Custom Business Assistant: Created a custom prompt with five facts and three rules.

## Project Files
- AgenticAI_Day1_SweetCrumbs.ipynb
- AgenticAI_Day1_SweetCrumbs.py

## Learning Outcomes
- Understood how to connect an LLM using an API.
- Learned the importance of system prompts.
- Explored temperature and response variation.
- Understood hallucination and conversation memory.
- Compared token usage across languages.
- Created a basic business-specific AI assistant.
